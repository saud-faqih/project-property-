# Real Estate Dashboard Project

## Introduction
This project is a data visualization dashboard that shows real estate market data in Saudi Arabia. It was developed as a group project to analyze property prices and transaction trends.

## Features
- Price map by region
- Top regions comparison
- Market price trend over years
- Number of transactions by property type (apartments, villas, land)
- Interactive filters

## Tools Used
- Tableau (for dashboard visualization)
- Excel / CSV (for data)
- GitHub (for project sharing)

## Purpose
The goal of this project is to analyze the real estate market and present the data in a clear and interactive way.
